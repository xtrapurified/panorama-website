    Unlinked page, for comparing only. The fuller file names are display labels: the number is the photo file’s own, the word is picked from a fixed set (panorama, fieldnotes, bts, crew, onset, loop) and the code is a checksum of the file name, so each photo always gets the same name. Sizes are the files’ own. The page keeps only a handful of photos loaded at a time and runs only while the frame is on screen.
